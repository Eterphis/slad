Aurora hairlines for the one big moment on a page: the hero or a loading screen.

The curtain belongs to the one big moment on a page: the hero, behind an illustration or a
display headline, never behind body copy. Give the container `position: relative`; add
`<div class="ct-curtain" data-ct-curtain aria-hidden="true"></div>` as its first child. For a
reflection below a waterline, add a second curtain with `data-ct-reflect` positioned from
75.8% to the bottom.
