# Logos

The Eterphis logo, identity 2.0. Files from the Cold Trace kit (`assets/eterphis/`), generated by its
builder `eterphis-mark.ts`; never edit or redraw them.

| File | Use |
|---|---|
| `eterphis-mark.svg` | Primary, full drawing, 256px. 56px and up. |
| `eterphis-mark-small.svg` | Small drawing, 40px. 24 to 55px. |
| `eterphis-mark-tiny.svg` | Tiny drawing, 16px. Below 24px. |
| `eterphis-mark-mono.svg` | One ink, for print, engraving and stamps. |
| `eterphis-wordmark.svg` | The drawn wordmark "eterphis", 64px high. |
| `eterphis-favicon.svg` | Favicon: hex colours, ice on dark tabs, near-black on light tabs. |

As `<img>` the files fall back to night colours (ice square), so put them on a dark ground. Inline,
with `eterphis-mark.css` loaded, they follow the page's mode and animate. Prefer the builder in code:
it sizes, labels and ids each copy. The full rules are in the Logo component and in the kit's
`references/eterphis.md`.
