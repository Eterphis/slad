# Textures

The grit tiles behind the page ground (`--ct-grit`). 256 × 256 px, seamless, transparent.

- `grit-dark.png`: blue specks for the night ground (#000000).
- `grit-light.png`: blue specks and white glints for the daylight ice ground (#D6E5EE).

Tile them at 256px on the page ground only, never on panels. `.ct` applies the right one
for the current mode.
